📋 项目概述

续热火锅 Pro 是一套基于你现有304自热饭盒的分体式续热改造方案。 通过旋钮旋扣结构把火锅分成上半（火锅本体）和下半（快拆加热仓）， 一拧就拆、一拧就合，换自热包速度从30秒降到≤5秒， 完美解决自热包只能用15分钟的痛点——火锅再也不会断火！

建议加水量250ml 标准 / 150ml 温和 / MAX 300ml 禁止超
换包速度≤ 5秒（旋钮90°拆卸→换包→旋钮90°锁止）
单次加热续航约15分钟（80g包+250ml水）
整套续航≥3小时（按需配包）
加热方式360°蒸汽包围 + 内胆底部支撑台阶导热
旋钮旋扣2对凸缘/凹槽 · 180°对称 · 90°旋转锁止
泄压安全加热仓4×φ5mm泄压孔 + 复用原饭盒心形排气孔
外壳表面温度≤ 45°C（安全触摸）

🔑 设计理念

  • 零破坏原则：不切原饭盒，重新打印完整的分体外壳，原内胆100%复用
  • 旋钮旋扣：像拧保温杯底座一样简单，90°=1/4圈就锁止，对盲操作友好
  • 内胆留在上面不动：换包时不用把内胆拿出来，水不会洒、温度不降
  • 后处理优于建模：泄压孔、加水口不做在STL里，打印后用钻/刀切反而更精准
  • 环氧树脂浸渍防漏水：FDM打印的层纹缝隙用环氧树脂填满，成本5元

旋钮旋扣原理

操作方法：把上下两个零件的旋钮凸缘/凹槽对准（约0°位置）→ 向内推 → 顺时针拧 90°（1/4圈）→ 听到"咔嗒"声 = 锁止完成！
拆卸：逆时针拧 90° → 分离 → 换包 → 重复。

为什么选2对凸缘/凹槽 + 90°旋转

方案优点缺点采用？
3对凸缘 + 30°旋转锁止力大需要精确对准3个点，对盲操作不友好❌
2对凸缘 + 90°旋转对盲友好、对得准、1/4圈快锁止力稍小（但足够）✅ 采用
4对凸缘 + 45°旋转锁止力大对准困难❌

🔧 后处理步骤（30分钟搞定）

去支撑
用镊子+斜口钳把所有支撑拆掉。旋钮凹槽里的支撑最后用φ3mm钻头转掉。
旋钮旋扣打磨（最关键！）
1200目砂纸打磨凸缘/凹槽的接触面。两个零件试着旋扣，拧90°顺畅不卡 = 合格。卡就继续磨。
加热仓切加水口
美工刀+钢尺，在加热仓侧壁距底18mm处切一个18×12mm的矩形口（用记号笔画线再切）。
加热仓钻泄压孔
φ5mm电钻，在加热仓侧壁距顶6mm处钻4个孔（90°均匀分布）。没有电钻用烧红的铁丝烫。
环氧树脂浸渍（防漏水！）
E-44胶+固化剂按1:3调。把加热仓泡进去10分钟让树脂渗进层缝→拿出来立刻擦干所有表面→60°C烤箱烤2h（或吹风机吹20min）→固化后1000目砂纸重磨密封面。
装硅胶密封圈
淘宝搜"φ2mm硅胶绳"（1元/米），剪一段套在旋钮旋扣面的密封槽里。多余剪掉，接头处压平。
标水位刻度
用记号笔在加热仓内壁标水位线：距底14mm处画绿线"150ml温和"、24mm处画红线"250ml标准"、29mm处画红警示线"MAX300ml禁止超"。
密封测试（必做！）
加热仓装300ml水→晃10秒→旋进上半外壳→整体晃10秒。任何地方漏水都要重涂环氧树脂！

✅ 组装 & 使用指南

首次组装（5分钟）

放入内胆
把原饭盒的304内胆（翻边朝上）放进上半外壳，翻边搭在内部台阶上 → 稳不晃 = 正确。
对准旋钮
下半加热仓的旋钮凹槽对准上半外壳底部的凸缘（约0°位置），把两个零件压紧。
锁止
顺时针拧加热仓 90°（1/4圈） → 听到"咔嗒"声 = 锁止完成！
开始加热
旋回加热仓→加水口翻盖翻开→放80g自热包→倒250ml水到250ml刻度线→盖回翻盖→放密封盖→等10分钟沸腾！

续热换包（≤5秒！）

逆时针90° → 拿下加热仓 → 倒旧包 → 装新包加水 → 顺时针90°锁止 ⏱ ≤ 5秒
